```bash
npm create mantlejs@latest my-app
```

<CardGrid>
  <Card title="Services are contracts" icon="puzzle">
    `Service<T>` defines the API; `Repository<T>` adapters do the data access. Swap Postgres for MongoDB or
    DynamoDB without touching a service.
  </Card>
  <Card title="One hook pipeline" icon="random">
    Authentication, validation, logging, and auditing are plain function hooks that run identically for REST,
    Socket.IO, and MCP callers.
  </Card>
  <Card title="Agent-native" icon="rocket">
    Expose services to AI agents over MCP — per-method tools or a sandboxed code mode — with scoped, revocable
    agent tokens and an audit trail.
  </Card>
  <Card title="Batteries, unbundled" icon="seti:config">
    Eight SQL, document, graph, and vector adapters; local and seven OAuth sign-in strategies; uploads to disk, S3,
    or GCS; OpenAPI; realtime sync — one package each.
  </Card>
</CardGrid>
